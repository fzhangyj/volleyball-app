# 底部导航栏图标说明

请在 `static/tabbar/` 目录下添加以下图标文件：

## 需要的图标文件

1. **home.png** - 首页未选中图标
2. **home-active.png** - 首页选中图标
3. **teach.png** - 教学未选中图标
4. **teach-active.png** - 教学选中图标
5. **offline.png** - 线下课程未选中图标
6. **offline-active.png** - 线下课程选中图标
7. **profile.png** - 我的未选中图标
8. **profile-active.png** - 我的选中图标

## 图标规格建议

- 尺寸：建议 81px × 81px（或按比例缩放）
- 格式：PNG（支持透明背景）
- 颜色：未选中状态建议使用灰色，选中状态建议使用主题色（如绿色或金色）

## 临时方案

如果暂时没有图标，可以：
1. 使用emoji表情作为临时图标
2. 使用在线图标库（如 iconfont）下载图标
3. 使用设计工具（如 Figma、Sketch）制作图标
