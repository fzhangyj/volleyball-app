# 排球少年·启程 · 界面规范

## 方向

面向排球初学者与爱好者的移动学习应用。以暖白、石墨文字和陶橙强调色形成清爽的运动风格，保留原有四个导航入口和学习流程。

设计参数：`DESIGN_VARIANCE: 5`、`MOTION_INTENSITY: 2`、`VISUAL_DENSITY: 4`。优先可读性和触屏操作；只在点击反馈、加载和游戏状态中使用动效。应用保持浅色主题，尊重系统减少动态效果的设置。

## 基础样式

共享样式在 `styles/theme.css`，由 `App.vue` 引入；`uni.scss` 同步 UniApp 主色。

| 用途 | 颜色 |
| --- | --- |
| 页面底色 | `#f7f8f5` |
| 内容表面 | `#ffffff` |
| 主要文字 | `#202521` |
| 次要文字 | `#667068` |
| 分隔与描边 | `#e5e9e2` |
| 主操作 / 选中状态 | `#b94b24` |
| 强调色浅底 | `#fff0e8` |

- 使用系统无衬线字体，中文优先系统黑体；不加载远程字体。
- 页面边距以 36rpx 为基准，模块间距 24–40rpx。
- 卡片圆角 22–28rpx，输入框与按钮 14–18rpx；主要依靠留白和描边分层。
- 主按钮使用橙底白字，次要操作使用浅底或文字样式。
- 首页与教学页使用原生 `button`，支持 H5 键盘焦点。不要给静态内容增加循环动画。
- 加载使用骨架或加载提示；无内容和请求失败分开呈现，失败提供重试。
- 游戏中用于判断题目的颜色独立于品牌色，不修改其语义。

## 页面与资源

- 首页：问候式标题、运动 Banner、开始练习、排球知识 / 本地课程、推荐课程。
- 教学：突出 AI 教练，规则、上课、技能、反应力四个训练入口。
- 线下：搜索筛选、课程卡片、详情弹层、加载和空状态。
- 我的：个人资料、四项学习数据、技能进度和已加入课程。
- AI：浅色聊天界面，明确区分提问和教练回复。
- 登录 / 注册 / 重置密码：沿用原字段与交互，统一输入框和按钮。
- `static/banners/` 是项目原有三张 Banner 的压缩副本；使用英文文件名解决原资源路径不匹配的问题。
- `static/icons/` 使用 Tabler Icons 3.31.0（MIT），预渲染为 PNG 兼容跨端 `image` 与原生 tabBar；许可证随目录保留。
- 原 `static/logo.png` 是 UniApp 默认图标。界面中的默认图标改用排球图形，原文件保留，已上传头像仍显示原照片。

## 验证边界

H5 使用本机 HBuilderX Vue 3 编译器构建；同时编译微信小程序产物。浏览器检查使用独立拦截的测试数据，不会向真实服务提交聊天、登录或报名请求。小程序真机、App 原生键盘和真实后端业务仍需在对应环境验证。
