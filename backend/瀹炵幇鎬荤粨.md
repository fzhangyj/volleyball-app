### 2. 数据库表结构设计 ✅

#### 新增数据表：
1. **banners** - Banner轮播图表
   - 字段：id, title, image_url, link_url, link_type, sort_order, is_active, created_at, updated_at

2. **rule_contents** - 规则内容表
   - 字段：id, title, content, section_title, section_order, image_url, sort_order, is_active, created_at, updated_at

3. **rule_progresses** - 规则学习进度表
   - 字段：id, user_id, rule_content_id, is_completed, completed_at, created_at, updated_at

4. **reaction_training_records** - 反应力训练记录表
   - 字段：id, user_id, game_mode, score, avg_reaction_time, hit_rate, total_rounds, hit_count, duration, created_at

5. **offline_courses** - 线下课程表
   - 字段：id, title, description, location, address, price, image_url, max_participants, current_participants, schedule_type, schedule_info, instructor_name, instructor_phone, is_active, sort_order, created_at, updated_at

6. **offline_course_enrollments** - 线下课程报名表
   - 字段：id, user_id, course_id, status, contact_phone, remark, enrolled_at, created_at, updated_at

#### 数据库自动初始化：
- 启动后端时会自动创建所有表结构
- 自动初始化默认数据（Banner、规则内容、线下课程等）

### 3. 后端API实现 ✅

#### 新增路由模块：

1. **Banner管理** (`backend/app/routers/banner.py`)
   - `GET /api/v1/banners/` - 获取Banner列表
   - `GET /api/v1/banners/{banner_id}` - 获取Banner详情

2. **规则内容** (`backend/app/routers/rule.py`)
   - `GET /api/v1/rules/content` - 获取规则内容
   - `POST /api/v1/rules/progress` - 保存规则学习进度

3. **训练记录** (`backend/app/routers/training.py`)
   - `POST /api/v1/training/reaction/record` - 保存反应力训练记录
   - `GET /api/v1/training/reaction/records` - 获取训练记录
   - `GET /api/v1/training/reaction/statistics` - 获取训练统计

4. **线下课程** (`backend/app/routers/offline_course.py`)
   - `GET /api/v1/offline-courses/` - 获取线下课程列表（支持搜索、筛选）
   - `GET /api/v1/offline-courses/{course_id}` - 获取课程详情
   - `POST /api/v1/offline-courses/{course_id}/enroll` - 报名课程
   - `GET /api/v1/offline-courses/my-enrollments/list` - 获取我的报名列表

## 四、使用说明

### 启动后端
```bash
cd backend
python start_server.py
```

### 数据库自动初始化
- 首次启动会自动创建所有表结构
- 如果表为空，会自动初始化默认数据

### 前端访问
- 确保后端服务运行在 `http://localhost:8000`
- 使用HBuilder运行前端项目

## 五、API认证说明

以下API需要JWT Token认证（在请求头中添加 `Authorization: Bearer {token}`）：
- 保存规则学习进度
- 保存反应力训练记录
- 报名线下课程
- 获取我的报名列表

如果Token过期或无效，前端会自动跳转到登录页。
